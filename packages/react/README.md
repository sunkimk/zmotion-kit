# zmotion

[Zmotion](https://zzmotion.vercel.app) 交互动效的 React 版：弹簧动效、手势和多端适配，装上即用，样式已内置。

```bash
npm install zmotion
```

```tsx
import { LikeBurst } from "zmotion";

<LikeBurst color="#FF3B5C" particles={12} />
```

每个组件的参数和网站详情页的参数卡一致，在网站上调好参数，代码页会给出对应的用法。SwiftUI 和 React Native 版见 [zmotion-kit](https://github.com/sunkimk/zmotion-kit)。
